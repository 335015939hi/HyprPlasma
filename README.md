# HyprPlasma

_this README generated by AI_

A Hyprland plugin aiming to bring KDE Plasma-style behavior and protocol compatibility to Hyprland.

HyprPlasma implements a focused subset of the Wayland protocols and desktop behaviors commonly expected by KDE Plasma clients, allowing them to interact more naturally with a Hyprland session.

## Why this project exists

Hyprland is a powerful compositor, but some KDE Plasma clients and applications expect a specific set of Wayland interfaces and desktop semantics. This project bridges that gap by exposing Plasma-compatible behaviors inside Hyprland without requiring a full KDE desktop environment.

## Features

- Implements the `org_kde_plasma_shell` protocol interface
- Handles Plasma surface roles such as panels, desktops, popups, and notifications
- Applies Plasma-style window geometry and positioning requests
- Supports virtual desktop management via Plasma protocols
- Reacts dynamically to Hyprland workspace and monitor state changes
- Built as a native Hyprland plugin using CMake

## Requirements

Before building, make sure you have:

- Hyprland installed with development headers and pkg-config metadata
- CMake 3.20 or newer
- A C++23-capable compiler
- `wayland-server` development libraries
- `PlasmaWaylandProtocols` installed
- `wayland-scanner` available in `PATH`

Important: Hyprland plugins are ABI-sensitive. Build this plugin against the same Hyprland version and compiler stack used by your running Hyprland session.

## Build

```bash
cmake -B build -S .
cmake --build build
```

A debug build can be configured with:

```bash
cmake -B build -S . -DCMAKE_BUILD_TYPE=Debug
```

## Install and load

The project installs its shared library to Hyprland's plugin directory by default:

```bash
cmake --install build
```

Then load it while Hyprland is running:

```bash
hyprctl plugin load /absolute/path/to/build/libhyprplasma.so
```

To unload it:

```bash
hyprctl plugin unload hyprplasma
```
